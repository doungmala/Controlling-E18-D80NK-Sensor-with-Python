# Controlling-E18-D80NK-Sensor-with-Python

งสำหรับการเชื่อมต่อและอ่านค่าจาก E18-D80NK Infrared Obstacle Avoidance Sensor (เซ็นเซอร์อินฟราเรดตรวจจับสิ่งกีดขวางแบบดิจิทัล) ด้วย Python ผ่านพอร์ต Serial 

คำอธิบายการทำงาน

E18-D80NK Sensor: เป็นเซ็นเซอร์แบบ Diffuse Reflective สามารถปรับระยะทางใกล้-ไกลได้ด้วยตัวปรับด้านหลัง เมื่อตรวจพบลักษณวัตถุในระยะที่ตั้งไว้ จะเปลี่ยนสถานะสัญญาณเป็น LOW

Serial Communication: Arduino ทำหน้าที่อ่านสถานะพินแล้วส่งข้อความผ่าน USB มายัง Python

Python Script: คอยดักฟัง (Listen) ข้อมูลผ่านพอร์ต Serial และนำข้อความที่ได้ไปเงื่อนไข (Condition) เพื่อสั่งงานระบบขั้นต่อไปได้ทันที
